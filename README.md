# 🐍 PyStep: Шлях до оферу

Інтерактивна освітня веб-платформа для вивчення Python з нуля до впевненого рівня Junior-розробника.

##  Навіщо створено цей проєкт

Цей сайт створений як особистий простір для системного навчання та підготовки до кар'єри програміста. Головна мета проєкту — закрити чотири ключові потреби під час вивчення мови:

1. **Глибоке розуміння замість зубріння:** кожна тема пояснює не просто синтаксис, а те, як код працює «під капотом» — на простих життєвих аналогіях і розборі кожного рядка.
2. **Щоденна мотивація та дисципліна:** гейміфікація (Streak днів поспіль, XP, кар'єрні рівні та нагадування про головну мету) допомагає не закидати навчання й повертатися до коду щодня.
3. **Постійна практика:** теорія одразу закріплюється легкими мікро-завданнями під час уроку, серією практичних задач з автоперевіркою в кінці теми та фінальним міні-проєктом.
4. **Готовність до реальних співбесід:** кожен модуль містить окремий блок із відповідями на популярні питання інтерв'ю у двох форматах — **простою мовою для HR** та **технічно для тімліда**.

##  Що реалізовано всередині

- **Справжній Python 3.11 у браузері:** код виконується прямо на сторінці завдяки рушію Pyodide (WebAssembly) без потреби налаштовувати середовище на старті.
- **Зручний редактор коду:** нумерація рядків, авто-відступи, миттєвий запуск і дружні підказки українською мовою у разі виникнення помилок.
- **Збереження прогресу:** пройдені уроки, виконані задачі, досвід (XP) та серія днів (Streak) автоматично зберігаються у `localStorage` браузера.
- **7 структурованих модулів:**
  1. *Що таке Python і як він працює* (інтерпретатор, виконання коду, основи)
  2. *Змінні та типи даних* (`int`, `float`, `str`, `bool`, типізація)
  3. *Умови та логіка* (`if / elif / else`, логічні оператори)
  4. *Цикли* (`for`, `while`, `range`, керування ітераціями)
  5. *Списки та колекції* (`list`, методи, зрізи, робота з наборами даних)
  6. *Функції* (`def`, параметри, `return`, області видимості)
  7. *Основи ООП* (класи, об'єкти, `__init__`, методи, інкапсуляція)

## 🛠 Технології

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Python Runtime:** Pyodide (Python 3.11 у WebAssembly)
- **Збереження прогресу:** Web Storage API (`localStorage`)
